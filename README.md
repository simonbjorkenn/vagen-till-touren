# Vägen till touren

Golfkarriärspel för mobilen: från Klubbserien till Världstouren.

Spela: https://simonbjorkenn.github.io/vagen-till-touren/

Lägg till på hemskärmen (Safari: Dela → Lägg till på hemskärmen, Chrome: ⋮ → Installera app), så startar spelet som en app, också utan nät.

Filerna här byggs automatiskt från spelets källkod (`build.py` + `pwa/build_pwa.py`). Ändra inte här för hand.
